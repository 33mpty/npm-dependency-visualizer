# Визуализатор npm-зависимостей

## Этап 3. Граф зависимостей

Нужен Python 3.9 или новее. Команды выполняются из каталога проекта.

`build_graph` сохраняет рёбра, `breadth_first` обходит вершины очередью
без рекурсии, а `has_cycle` определяет наличие цикла. Вершина — пара
из имени и версии. Тестовый граф читается из JSON и работает без сети.

| Команда | Результат |
| --- | --- |
| `./run.sh demo` | Все три локальных примера |
| `./run.sh --stage 3 --config examples/cycle.csv` | A, B, C, D в порядке BFS, ребро C → A и признак цикла |
| `./run.sh --stage 3 --config examples/diamond.csv` | Два ребра к D, цикла нет |
| `./run.sh --stage 3 --config examples/isolated.csv` | Только A, рёбер нет |

В реальном режиме диапазоны версий разрешает `src/depviz/semver.py`.

## Проверка

`./run.sh test` запускает автотесты текущего этапа и предыдущих этапов.
