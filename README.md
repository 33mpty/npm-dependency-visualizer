# Визуализатор npm-зависимостей

## Этап 4. Обратные зависимости

Нужен Python 3.9 или новее. Команды выполняются из каталога проекта.

`reverse_dependencies` инвертирует рёбра. Для прямого ответа
используется список родителей цели. С `--transitive` по этому списку
запускается тот же BFS, что и на предыдущем этапе.

| Команда | Результат |
| --- | --- |
| `./run.sh demo` | Ромб, цикл и одиночная вершина |
| `./run.sh --stage 4 --config examples/diamond.csv --target D --transitive` | Прямые B, C, E. Полный результат B, C, E, A |
| `./run.sh --stage 4 --config examples/cycle.csv --target A --transitive` | Прямая C, полный результат C, B |
| `./run.sh --stage 4 --config examples/isolated.csv --target A` | Обратных зависимостей нет |

В тестовом режиме поиск охватывает весь JSON. В реальном режиме
он ограничен графом, достижимым из корневой версии.

## Проверка

`./run.sh test` запускает автотесты текущего этапа и предыдущих этапов.
